# 图片裂变

公开独立 Skill，版本 **1.2.0**。根据原图和可选的人物、产品、服装、场景或拍摄状态参考，完成换人换品、局部修改、姿态调整和独立图片变体，适用于电商视频首帧。需要宿主提供实际可用的图片生成或编辑工具，不附带模型、账号或凭据。

## 当前工作方式

实际查看参考图，分别确定原图、保留项、改动项和参考用途，再按要求生成独立图片并对照原始参考检查。只换产品或场景时沿用未要求改变的机位、姿态和空间关系；明显重构姿态或机位时先验证基础版。人物身份优先自然融合和相似度，商品检查结构、材质、尺度与手部接触。

用户指定数量优先。没有指定数量时，明显重构先出一张基础版；有参考的普通换品默认 S/M/L 三张；严格身份还原与换品同时进行时先完成 M，再扩展 S/L。生活感任务避免为了完整展示商品和身体而擅自拉远镜头或重排姿态。

同一目标默认首轮加最多两轮纠正；多版本整批默认最多两次追加修正调用。已有费用授权和用户指定预算优先，换提示词或继续反馈不清零次数。提交状态不明时先查询现有任务及计费。用户只要求分析或提示词时不生成图片。

本版只使用本次素材、指令与任务记录，**不读取或维护跨任务策略库、经验库或自优化状态**。旧版的自优化模块已从技能包移除；安装升级不删除安装目录以外的个人历史数据。

## 安装与调用

可安装目录是 [skills/image-fission](skills/image-fission/SKILL.md)，完整复制到目标平台的用户级技能目录。Codex 对应用户 `.codex/skills/image-fission/`。也可下载 [dist/image-fission.zip](dist/image-fission.zip)，包根目录包含 `SKILL.md` 与 `agents/openai.yaml`。

仓库公开，无需 GitHub 账号或令牌即可下载。现有同名安装先备份并比较本地改动，再整体替换技能目录，避免残留旧版脚本与配置。详见 [INSTALL-PROMPT.md](INSTALL-PROMPT.md)。

调用示例：“用 `$image-fission`，图1换成图2的脸，服装妆容保持，手里的产品换图3。”

## 维护与验证

```text
python -X utf8 scripts/build.py
```

修改 `skills/` 后重建 `dist/` 和 `manifest.json`。构建脚本验证压缩包可读并逐文件核对内容；清单记录版本和 SHA-256。行为检查场景见 [tests/scenarios.md](tests/scenarios.md)。发布核验不代表已通过实际生图或用户验收。仓库更新不会自动更新其他电脑的安装。
