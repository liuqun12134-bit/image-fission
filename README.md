# 素材万象 · 图片裂变

独立 Skill，版本 **1.0.0**。从原图片裂变插件迁移并加入任务策略、三轮自检修正、模型兜底咨询和可选自优化。需要宿主实际提供图像生成/编辑工具，本包不内置模型服务或凭据。

## 工作方式

解析参考角色和保留/替换项 → 按任务检索策略与经验 → 实际生成 → 对照原参考自检 → 通过即交付，未通过最多再修两轮 → 仍不通过时展示最佳结果，准备换模方案并咨询。

同一目标最多三轮，跨反馈继续计数；多版本整批默认最多两次追加修正调用，不自动对每张都改三轮。严格身份还原先验证一张基准再扩展 S/M/L。用户指定更小预算优先。技术失败先恢复现有任务，不能借失败不断追加付费提交。

策略覆盖换人、换品、换装、换景、构图与组合编辑。换脸分开看结构、口型、发型、肤色和光照，亮面产品检查反射、透明关系和手指接触；用户锁定项始终保留。

换模可提议 GPT Image 2.5 Sunburst，实际模型 ID、参数、费用和授权以可用服务为准。不会把内置工具假称为该模型，不自动上传媒体或跨服务付费。

## 安装与调用

可安装目录是 [skills/image-fission](skills/image-fission/SKILL.md)，完整复制到目标平台的用户级 Skills 目录。Codex 对应用户 `.codex/skills/image-fission/`；现有同名安装先备份并保留改动。也可下载仓库 [dist/image-fission.zip](dist/image-fission.zip)，包根目录就是 SKILL.md。私有仓库需要已有 GitHub 访问权限；GitHub 网页可下载 ZIP。完整安装提示见 [INSTALL-PROMPT.md](INSTALL-PROMPT.md)。

调用示例：“用 `$image-fission`，图1换成图2的脸，服装妆容保持，手里的产品换图3，注意亮面融合。”

## 自优化开关

默认关闭。说“开启图片裂变自优化”，之后 agent 在任务结束/后续反馈时判断有无新经验，有才记录；说“关闭自优化”后不自动写，但继续读取已有库。也支持手动记住、查看最近经验、撤回和提升策略。

模型自评保持未确认，用户反馈只确认其明确范围。单次成功保留为案例，自动提升策略需两个独立任务的有效反馈。既有证据、反例、修改前后历史保留；不会自行改权限、预算、核心规则或训练模型。

个人开关与经验/策略保存在用户 `.local/share/skill-learning/image-fission/state.json`，可通过 SKILL_LEARNING_HOME 更改根目录。此数据在安装目录之外，升级保留；迁移另行复制，**不随 GitHub 代码同步**。无 Python 3.10+ 或持久写权限时，需如实说明没有永久保存。内置案例只包含去标识文字摘要，无私人媒体。

## 维护与验证

```text
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts/build.py
```

修改 skills/ 母版后重建 dist/ 和 manifest.json。包内文件与 ZIP 的 SHA-256 可核对完整性，不能证明图像质量。单元检查覆盖开关、隔离、证据、去重、回撤、并发写入和持久存储；行为边界见 [tests/scenarios.md](tests/scenarios.md)。本次升级没有调用付费生图来验证，实际图像效果仍需具体任务检查。仓库更新不自动更新其他电脑的安装。
