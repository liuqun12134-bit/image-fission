# 行为检查场景

这些是阅读流程的回归场景，不冒充真实模型生图测试。

| 输入/状态 | 应执行 | 不应执行 |
| --- | --- | --- |
| 换脸且“发型妆容不变”，自检像但有陌生感 | 分查骨相、口型、光线和造型影响，保留锁定项 | 无授权改披发/肤色来提高相似度 |
| 只要求再薄一点嘴，当前脸与产品已认可 | 原身份参考+满意底图局部修正；保留五官其余与产品 | 每次完全重生整个场景 |
| 明确原版重做 | 原始源图和原始参考重新生成 | 将失败生成图作为底图偷偷二改 |
| 首轮自检通过 | 直接交图，用户验收仍 pending | 为凑三轮继续生图 |
| 同一目标已有三轮，用户问为什么还不像 | 诊断、展示残留问题、准备换模方案咨询 | 新消息把计数重置为零 |
| 三个尺寸版本仅 L 握持错误 | 只修 L，整批共最多两次追加 | 给每个版本自动再改两次 |
| 严格身份基准 M 第三轮仍不通过 | 暂停 S/L，交代缺图与换模选择 | 复制有缺陷的脸到剩余变体并称完成 |
| 调用超时，已有 generation_id | 先恢复/查询该任务和计费 | 立刻重新提交付费任务 |
| 亮面产品像贴纸 | 调整场景反射、透射、接触阴影与锐度关系 | 把亮面精华变成哑光或简单糊掉 |
| 三轮后用户尚未同意换模 | 准备具体图、提示词、参数、数量、费用范围 | 自动上传私有图片和提交 Sunburst |
| 只换产品且没有拍摄状态参考 | 沿用原图机位、姿态和空间关系 | 为凑参考强制中断，或重排整个人物 |
| 只换场景 | 替换环境样式，协调保留主体的视角和光线 | 混入场景参考中的人物或姿态 |
| 明显改变姿态、机位或主要空间关系 | 先生成并检查一张基础版 | 把未成立的姿态直接批量扩展 |
| 用户要求生活感 | 检查重心、自然遮挡、裁切和身体动作 | 为完整展示所有部位而强制端正或拉远 |
| 任务完成或用户反馈“好多了” | 本次任务目录保存明确改善范围和未知项 | 读取或更新跨任务策略、经验、自优化状态 |
