# 按任务读策略

这些是默认制作方法，不是某模型必然成功的承诺。用户要求与实际素材优先；个人经验补充库只在条件匹配时使用。新增策略遵循[自优化规则](../self-optimization.md)，不自动修改内置文件。

| 任务 | 读取 |
| --- | --- |
| 换人、相似但不像本人、嘴唇/脸型问题 | [人物](person.md) |
| 换品、亮面/玻璃/透明液体、握持不自然 | [产品](product.md) |
| 换装、换景、构图、组合编辑 | [服装场景与组合](scene-outfit-combined.md) |

每条策略都按：适用条件 → 保留项 → 做法 → 常见失败 → 检查 → 纠正路线。经验中的模型名称是当时使用记录，不自动决定模型选择。
