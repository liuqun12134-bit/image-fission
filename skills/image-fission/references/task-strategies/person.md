# 换人与身份相似度

**适用**：有身份参考换人，或用户说“很像但不是同一个人”。**保留**：当前明确的发型/妆容/服装/姿态/背景等锁定项。不得因脸型诊断擅改锁定项。

**做法**：把身份锚点与造型锚点拆开。参考板只提供同一人的证据，不能复制拼版构图；看角度最接近的原参考，再用其他角度核验。先描述相对关系：颧部与下颌宽度、颊部凹凸转折、下巴长度与收束、眼距与眉眼走向、鼻翼和人中、嘴宽与上下唇红部关系。不要套“标准瓜子脸/完美流畅轮廓”。有轻微倒三角、颧下转折时保留观察到的差异，不夸大成尖削脸。

口型分开检查：闭合程度、上下唇红部厚度、嘴角宽度、人中到唇峰关系、下唇与下巴距离。微张嘴要保留自然缝隙；厚唇感也可能来自唇线外扩、反光、深唇妆或下颌角度。先找原因，再写“恢复参考的唇缘/开合与比例”，不要连轮加“薄15%”并宣称精确变形。

**常见失败**：平均化漂亮脸、肿脸/面颊饱满、轮廓过分平滑、嘟唇、把张嘴画成厚唇、保留了旧人的五官；反复二改积累漂移；完全重生破坏已经正确的局部。

**检查**：对照原参考分别评估结构、口型、发型轮廓/发际线、肤色和曝光、妆容、视角与表情。相似但有距离感时先辨别哪些是结构，哪些只是视觉线索；光线改变下不要用单一肤色色值判定身份。

类似案例可按需读[经验摘要](../experience-library.md)，注意当时的发型/肤色修改有额外用户授权。

**纠正**：局部错误且底图已满意→局部修改+原身份参考；全脸骨架错误/用户要求原版→原始参考重做。发型或肤色被锁且确实影响相似度→具体说明，只有用户解锁才改。停止在同一错误上累加形容词；预算内验证一次明确假设，达到上限走换模咨询。
