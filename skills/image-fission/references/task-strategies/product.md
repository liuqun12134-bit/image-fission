# 换品与亮面融合

**适用**：替换手持/桌面产品，尤其亮面金属、透明玻璃、精华液。**保留**：商品身份、长宽高关系、数量、盖体与内部结构；原场景镜位、已满意的人物和造型。

**做法**：原产品完全移除；将参考当作产品结构权威，不把棚拍图光照原封不动贴入场景。观察可见盖体结构、透明度、液体颜色和液位、内部物体；看不见的背面、小字与内部结构不编造。手持尺寸结合已知真实规格与透视，不按商品白底图画布大小换算。

让产品处在同一个光场：主高光方向、宽度和明暗符合环境光源；金属有环境反射，玻璃有透射/折射与适当边缘，液体/内物透过瓶体可见；手指在前后形成正确遮挡、接触阴影与受力。产品清晰度、颗粒、景深、曝光与人物处于同一拍摄层次。

**常见失败**：白底棚拍高光被保留、瓶体像贴纸、反光白条抢眼、无手指接触阴影、产品过亮/过锐、透明部分不透环境、金属被改成哑光、盖子/瓶身变形、旧品边缘残留。

**检查**：数量与结构、透视尺度、手指接触、材质、反射与环境关系、透明部件、标签可辨性。正面标签不应牺牲自然握持；不以“降低亮度/模糊瓶子”替代物理融合。

**纠正**：优先重建当前瓶体受光/接触与透明关系，保留已正确的瓶身位置和大小；结构错则先修结构再调光。文字无法可靠还原时明确未核实；用户要去文字才去，不擅删品牌。S/M/L 用展示距离和握持合理改变表观占比，不做拉伸。
