# 每轮视觉自检

实际查看生成结果及对应原参考；工具完成不是通过。必要时使用只裁切/缩放的对照图做检查，不以 AI 重绘参考替代证据。检查按任务相关性选择，给 pass / fail / unknown / not_applicable，并写可见依据。

| 检查 | 关注内容 |
| --- | --- |
| 锁定项 | 是否误改衣发妆、姿势、背景、数量与画幅 |
| 人物身份 | 换人对照新参考；保留人对照原人。轮廓转折、五官比例、口型，以及发型/肤色/角度的感知影响 |
| 产品 | 本体比例、盖体、液体/内物、数量、标识、透视与手部尺度 |
| 融合 | 握持受力、遮挡接触、阴影、亮面高光、透明/折射、清晰度与场景光照 |
| 画面 | 衣物头发边缘、空间反射、景别与主体位置、独立图片可用性 |
| 首帧 | 嘴眼可用、手和产品有延续动作空间，不引入无要求的文字或配饰 |

用户明确锁定项违反、脸部/产品结构明显不符、握持穿模或显著贴图感为关键失败，不能取平均分掩盖。核心项 unknown 时补看可用原图；仍无法判断则如实交付不确定性，不能谎称已通过。小字不可辨可单独列需核对，不凭猜测认定准确。

判断输出要区分：`model_review=pass`、`user_acceptance=pending`；用户明确认可才更新后者。用户说“好多了”只支持改善，不能扩成全部验收或精确身份相同。自检没有确定缺陷时直接交付，不因不可能保证100%而无限纠正。

每次纠正记录：观察到的问题 → 原因假设 → 修改的最小范围 → 必须保留的满意项 → 新一轮对照结果。同一指标停滞时在预算内换纠正方法；达到上限准备换模，不机械追加“更真实、更像”。
