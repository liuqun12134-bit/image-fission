# 三轮后换模兜底

默认先内置工具；不能通过提示词宣称已把内置工具切成某个指定商用模型。用户指定模型且当前有相应工具时以明确选择为准。Skill 不保证某模型/路由永久可用。

达到同一目标三轮或批次调用上限仍有关键缺陷：保留最佳图，写清剩余问题与已满意部分。准备候选模型、编辑底图、原参考、最终编辑提示词、张数/尺寸、预估费用和新的明确调用上限，再询问是否切换。已有授权覆盖这些范围时直接继续，不重复询问；仅授权“看看价格”不等于提交付费生成。

优先可提议 **GPT Image 2.5 Sunburst** 作为本用户身份/局部编辑任务的候选，不把单例变成普遍排名；Gemini 曾在一个案例中不符合用户预期，不设全局淘汰名单。无可用路由就明确说明，不用其他模型冒名。

Fish Audio 接入时按实际工具能力：

1. 发现 image/edit 模型目录（如 `list_media_models`），精确核对展示名称和 ID；读取 `get_media_model` 的输入角色、参数、大小限制和 prompt policy。不得猜 ID。
2. 明确本次授权是否包含上传和付费。已有完成素材的 object_key 可复用，不重复下载上传。尚未授权上传的本地媒体先备好清单和本地提示词，费用只能标暂估；只能在授权覆盖后使用当前上传接口，再进行准确校验/估价。
3. `estimate_image_edit` / `estimate_image_generation` 是成本校验；不是授权或保证锁价。说明积分/张数和参数；额度或价格变化超出现有授权时停止并重新询问具体变化。
4. 经授权后用匹配估价参数提交；持久记录 request_id/generation_id、使用模型和成本。丢响应先按接口要求恢复，按 poll_after_seconds 等待查询，不重复收费提交。
5. 使用实际返回媒体做同一质量检查，保留原身份/产品参考。只修发型肤色时不要重新洗掉正确五官。切换默认只试已确认的一次，不自动再启动另一套三轮；额外次数须在新的明确预算内。

没有 Fish 插件时可用用户明确指定的其他实际服务，但不能复制会话里的密钥进 Skill、脚本、仓库或日志。只把中立编辑任务交给真实可用的接口。
