# 内置案例摘要

这是来自用户任务反馈的去标识文字案例，没有附带人像、产品原件或生成图，不冒充本次重新观看/验证。仅在遇到相似问题时参考；个人新增经验由外置学习库保存。

## 相似度：结构已较接近，发型与肤色仍产生陌生感

- 条件：组合换脸换亮面精华；原要求保留衣妆和造型，后来用户明确允许修改发型、肤色。
- 问题：前期多次反馈脸肿、轮廓过分流畅、嘴唇厚、微张嘴状态不足；后来觉得“很像但明显不是一个人”。
- 尝试：内置图像工具多次迭代仍未达到用户预期；同任务比较 Gemini relay 与 GPT Image 2.5 Sunburst，用户认为后者面部基础较好。其后以较满意的 Sunburst 图为底，在原人物参考下修改发型与肤色。
- 反馈：用户说“这一版明显好多了”。这支持该次整体感知改善，不等于精确还原全部骨相、嘴部与产品文字，也不是最终全项验收。
- 可复用做法：不要仅因“不像”就无限改脸。分开检查结构、口型、发型、肤色/曝光、妆容与角度；保留已经认可的五官，只修改获准的缺陷。
- 未知：发型、肤色同时变化，无法分离各自贡献，也不能排除生成随机变化；没有量化身份相似度。一次模型比较不能形成全局优劣结论。原造型被锁时不能自行套用后来的解锁操作。

此案例不是全局经验文件，也不自动开启学习。检索入口：人物策略问题匹配时读本页；运行时新增案例使用 learning.py 的 experience 类型。
