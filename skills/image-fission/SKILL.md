# 图片裂变

根据用户的原图、参考图和本次要求，调用实际可用的图片生成或编辑工具，检查并交付独立图片。不附带模型或账号。只使用本次素材、指令和任务记录，不读取或维护跨任务策略库、案例库、个人经验或自优化状态。

## 看图并确定改动

实际查看参与任务的图片，先确定要编辑的原图、要改的属性和保留项，再分配参考用途。默认沿用原图的构图、机位、姿态、空间关系及未要求修改的内容。独立的拍摄状态参考是可选输入，不要求用户凑齐一套参考图。

| 本次改动 | 参考分工 |
| --- | --- |
| 只换产品 | 原图提供人物、穿搭、场景、机位和身体状态；产品参考决定新商品，无需另给拍摄状态图 |
| 只换场景 | 原图提供人物、穿搭、产品、机位和身体状态；有场景参考时按其环境样式替换，没有时按文字要求设计 |
| 换产品并换场景 | 分别替换商品和环境；未要求改变的机位、姿态及空间关系仍沿用原图 |
| 改变姿态、机位或主要空间关系 | 重新确定构图基础；有适用的拍摄状态参考时借用对应关系，没有时按需求设计，不因缺图强制中断 |

图片顺序不代表优先级。一张图可承担多个用途，同一属性有多张参考时按用户指定的用途和范围取舍。人物身份、服装、发型妆容、拍摄状态、产品和场景分别遵从对应依据；参考只影响被分配的属性，不整体覆盖其他内容。例如，只换脸时不连带采用人物参考的衣服；借用坐姿时不连带采用姿态参考的长相、发型和背景。参考用途能判断时直接判断，可能换错核心对象时才简短确认。

本次明确要求优先。只换背景就保留人物、服装和产品；只换五官就保留指定的发型、妆容和表情。用户要求从原版重做时，重新使用原图及原始参考；普通局部修改可以使用已选定的结果，并继续用原始人物、产品参考检查漂移。

没有对应参考时，可以按需求设计新人物、服装、场景或概念产品；精确还原某个人或真实商品需要对应依据。多视角产品图表示同一产品，不代表多件商品。

比例按用户要求，否则沿用本次构图母图的有效画面比例；未另选母图时沿用原图。明确要求竖屏口播首帧且未指定比例时默认 9:16。截图中的播放器界面、黑边和边框不属于有效画面；不拉伸人物或商品。

## 编排图片

先区分局部替换与姿态重构。单纯换人、换品、换装或换景时，只调整完成替换所必需的部位。站变坐、近景变半身、新增桌面或明显改变手持动作时，需重新安排相应的机位、重心、肩臂和接触关系。

- 拍摄状态：有参考时，优先借用与目标动作有关的镜头距离和角度、人物画面占比、身体朝向与重心、头肩及肩臂关系、支撑位置、桌面高度、前后距离和裁切。用户只指定其中一部分时不强行继承全部。没有参考时按目标动作安排这些关系，先用基础版验证。
- 换人：优先身份相似度和自然融合，分别检查脸部结构、五官比例、口型、发型、肤色、妆容、角度和光照；不把“不像”一律处理成瘦脸或美颜。
- 换品：产品参考直接决定生成外观，也用于复核。保留商品结构、长宽高比例、盖体、材质、颜色、可辨标识和要求的开合状态，结合手部尺度、透视、握持接触、遮挡、反光与清晰度安排展示。已知真实尺寸优先。握持不兼容时先判断商品与动作是否适配，再调整必要的手指、手腕和前臂；确需改变肩臂或身体时说明原因，不为摆正标签而重新安排整个人的姿势。
- 换装、换景：服装贴合身体姿态。场景参考默认提供环境样式、材质、陈设和光照依据，不自动接管机位和人物动作。新环境应与保留的主体视角、支撑面、距离和光线协调，避免为了展示场景增加一套不连贯的桌面或改变人物位置。没有参考的多版本要有款式或空间差异。
- 生活感、随拍感或自然口播：保留目标参考或动作所需的重心、透视、自然遮挡与裁切。不要额外叠加双手完整入镜、身体端正、标签正对镜头、背景陈设全部可见等展示要求。前倾、低机位、手部出画只是可能的表现，不作为所有任务的默认姿态；用户要求广告展示或摆姿时按其要求处理。
- 保留用户已经认可的内容，只针对本次问题修改。视频首帧按后续动作给眼睛、嘴部、手和产品留下必要空间，不为完整交代所有部位而擅自拉远镜头。

## 确定数量和版本

用户指定张数优先；“试试看”等试做请求默认一张；修改选中版本只改该版。每个版本是独立图片，不用拼图代替。其余按下表确定数量：

| 需求 | 未指定数量时 |
| --- | --- |
| 明显重构姿态、机位或主要空间关系 | 一张基础版，先验证身份、动作、空间和产品；后续按用户选择和要求扩展 |
| 换品且有产品参考，不涉及上述重构 | S 小展示、M 自然平衡、L 突出展示，三张 |
| 换品但无产品参考，不涉及上述重构 | 三种概念；外观已明确时比较展示尺度 |
| 无参考换人、换服装或换场景，不涉及上述重构 | A/B/C 三个有实质差别的候选 |
| 有参考且不属于以上情况 | 一张忠实替换 |

用户已明确要求多张重构版本时，先生成并检查基础版，再在原有授权和预算内完成其余版本，无需为继续已要求的工作再次确认。基础版的共性缺陷先修正，不把尚未成立的姿态批量扩展。

S/M/L 通过合理的递近、握持调整画面展示大小，不改变商品本体比例，也不破坏明确要求保留的姿态、机位与空间关系。严格身份还原和换品同时进行时，先做好一张 M，再扩展计划中的 S/L。换品与无参考换装、换景组合时，先固定一套造型比较产品尺度；后续扩展按用户选择和授权继续，不自动扩大组合数量。

## 生成、检查和修改

默认使用宿主可用的图像生成或编辑工具；用户指定可用模型时遵从。先明确保留项、替换项、参考分工和版本差异，再调用工具。只要求写提示词或分析时，交付文字即可；没有生图能力时如实说明未生成。

实际打开结果，按属性与对应的原始参考比对：

- 人物身份及要求保留的服装、发型、妆容是否正确，有无混入姿态或场景参考中的人物外观。
- 机位、构图、重心、肩臂、支撑接触和前后透视是否符合目标，是否为了展示而擅自拉远镜头或重排身体。
- 产品结构、数量、开合状态、尺度、手部接触、材质光影、反光和清晰度是否可信。
- 背景是否完成要求的替换，与人物和桌面等支撑物是否连贯，有无把母图背景错误保留下来。
- 输出比例是否正确，截图界面、黑边或拼图布局是否被误带入成品。

要求自然感时，额外检查身体和手部是否在完成目标动作，是否因过度端正、强制展示和不必要的完整构图产生摆拍感。解剖正确或产品清楚不能替代这项检查。按问题归属修正，保留已经正确的其他部分。

检查无明显缺陷后交付；有明确缺陷时，在已有费用授权和调用预算内做针对性修正。无法判断的细节说明不确定，不把工具成功、模型自检或自己的检查当作用户验收。

同一目标默认首轮加最多两轮纠正，共三轮；多版本整批默认最多两次追加修正调用，不能每张各追加两次。用户指定的更小预算优先。达到上限仍有明显问题，交付最佳现有结果、说明残留问题，并准备具体的换模或追加方案；已有授权未覆盖时再询问，不能自行扩大收费调用。

只在本次输出目录保存任务记录：原始参考及用途、保留项与改动项、版本、实际结果、调用次数、任务编号及检查结果。更换提示词、母图或继续反馈不清零次数。提交状态不明时先查询原任务和计费情况，不重复提交；技术失败与质量失败分别记录。这些记录用于恢复本次任务，不用于跨任务学习。

## 交付

展示实际生成的图片，给每张一个短标签和必要的差异说明。保留已认可内容；包装小字、身份或其他无法核实、尚未满足的部分明确指出。用户选中首帧后，可将选定图片和原始人物、产品及拍摄状态参考（如有）交给后续视频流程。
